TLS

Headscale handles ACME directly. Requires a public DNS record pointing to this server and the chosen challenge port reachable from the internet.

Must resolve in public DNS to this server's public IP.

Provide your own certificate. Files must be inside the bind-mounted ./data directory (visible to the container at /var/lib/headscale/).

Heads up: enabling TLS doesn't change the listen_addr. If you want HTTPS on port 443 you'll typically also need to update listen_addr (in the raw YAML editor below) and expose port 443 in compose.yaml.
